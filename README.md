# Frontier Empires: War & Survival

A mobile-first, browser-playable strategy RPG prototype. No build tools or dependencies are required: the game is a standalone `index.html`.

## Play locally
Open `index.html` in a modern browser. Your campaign save uses the browser's local storage on that device.

## Current prototype features
- 12 territories to explore, claim, and conquer
- Recruit footmen, rangers, and cavalry
- Treasury, food, daily income, and army upkeep
- Randomised campaign battles, troop losses, and territory capture
- Capital fortifications and resource trading
- Campaign chronicle, save/load, and mobile-friendly layout

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish. The URL will appear in the Pages section.

The game is an early prototype; battle balancing, deeper quests, companions, and richer visuals are planned. It is not yet a finished commercial release.
